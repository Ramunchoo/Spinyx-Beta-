## Installer sur Windows

### 1. Télécharger

Clique sur le bouton de l'encart **Windows** ci-dessus : le téléchargement de la dernière version
démarre tout seul (fichier **`Spinyx-Setup.exe`**).

Ton navigateur peut dire que le fichier **« n'est pas couramment téléchargé »** (l'application est
récente et pas encore signée numériquement). C'est normal :

- **Chrome** : dans la liste des téléchargements, clique sur **Conserver**.
- **Edge** : survole le téléchargement, clique sur **⋯** → **Conserver** → **Afficher plus** →
  **Conserver quand même**.

### 2. Installer

1. Ouvre le fichier téléchargé.
2. Si Windows affiche **« Windows a protégé votre ordinateur »** : clique sur
   **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Suis l'installation, puis lance **Spinyx** depuis le raccourci du bureau.

## Installer sur Mac

### 1. Télécharger

Clique sur le bouton de l'encart **Mac** ci-dessus : le téléchargement de la dernière version démarre
tout seul (fichier **`Spinyx-Mac.dmg`**). Le même fichier marche sur les Mac Intel et les Mac à puce
Apple.

### 2. Installer

1. Ouvre **`Spinyx-Mac.dmg`** (dans tes Téléchargements).
2. Glisse l'icône **Spinyx V2** sur le dossier **Applications**.

### 3. Première ouverture

Apple ne connaît pas encore Spinyx : la première fois, ton Mac le bloque et affiche une alerte. Ce
n'est pas un virus, c'est le message qu'il montre pour toute application qu'Apple n'a pas encore
vérifiée. Tu n'as à le faire qu'une fois. Ensuite, Spinyx s'ouvre d'un double-clic.

**macOS 15 ou plus récent**

1. Dans **Applications**, double-clique sur **Spinyx V2**, puis clique sur **Terminé** dans le message
   du Mac. S'il propose **Placer dans la corbeille**, ne clique pas dessus.
2. Ouvre le menu Pomme → **Réglages Système** → **Confidentialité et sécurité**, puis descends tout en
   bas jusqu'à la partie **Sécurité**.
3. À côté de **« Spinyx V2 » a été bloqué pour protéger votre Mac**, clique sur **Ouvrir quand même**.
4. Si le Mac le demande, entre le mot de passe de ta session ou utilise Touch ID.
5. Dans la dernière fenêtre, clique sur le bouton bleu **Ouvrir quand même**.

**macOS 13 ou 14**

1. Dans **Applications**, fais un clic droit (ou Ctrl-clic) sur **Spinyx V2**, puis choisis **Ouvrir**.
2. Dans la fenêtre qui s'affiche, clique sur **Ouvrir**.

Le guide complet, avec les images, est dans le fichier **`Spinyx-Mac.dmg`** : **À lire d'abord.pdf**.

Pour connaître ta version de macOS : menu Pomme → **À propos de ce Mac**.

> Le HUD sur les tables n'est pas encore disponible sur Mac.

## Ensuite, sur Windows comme sur Mac

### Créer ton compte

Au premier lancement : choisis un **pseudo**, entre ton **email** et un **mot de passe**. Tu reçois
un **code** par email (regarde aussi dans les spams) : entre-le, c'est prêt.

### Importer tes mains

Onglet **Import** : dépose tes historiques de mains Betclic (fichiers `.txt` ou `.zip`).

---

### Mises à jour

Rien à faire : l'application se met à jour **toute seule**.

- **Windows** : quand une nouvelle version est prête, un bandeau propose de redémarrer ; sinon elle
  s'installe à la prochaine fermeture.
- **Mac** : Spinyx doit être dans le dossier **Applications** pour pouvoir se mettre à jour. Après une
  mise à jour, le Mac peut redemander l'accès à un dossier : réponds **Autoriser**.

### Tes données

Tes mains restent **sur ton ordinateur** : elles ne sont jamais envoyées en ligne. Ton compte sert
uniquement à accéder à l'application.
